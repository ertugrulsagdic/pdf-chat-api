# PDF Chat API

This project is a FastAPI application that allows users to upload PDF documents, extract text and metadata, and interact with the content via a chat interface. The application uses a Large Language Model (LLM) to answer questions about the content of the PDFs. 

## Table of Contents

- [Overview](#overview)
- [Features](#features)
- [Installation](#installation)
- [Usage](#usage)
- [API Endpoints](#api-endpoints)

## Overview

The PDF Chat API lets users upload PDF files, extract their content, and ask questions about the content. The application integrates with an LLM (such as Google Gemini API) to provide accurate answers based on the text of the PDF. It also includes metadata extraction and error handling for different file types and issues that may arise during processing.

## Features

- **PDF Upload**: Upload PDFs and extract text and metadata (file size, page count, etc.).
- **Chat Functionality**: Ask questions about the uploaded PDF content and receive answers generated by an LLM.
- **Metadata Storage**: Metadata for each PDF is stored in a JSON file.
- **Error Handling**: Robust error handling for invalid PDFs and API failures.

## Installation

### Requirements

- Python 3.10
- chromadb==0.5.13
- fastapi==0.115.2
- langchain==0.3.3
- langchain_chroma==0.1.4
- langchain_community==0.3.2
- langchain_core==0.3.10
- langchain_google_genai==2.0.1
- langchain_text_splitters==0.3.0
- pydantic==2.9.2
- python-dotenv==1.0.1

### Setup

1. Create a conda environment:

    ```bash
    conda create --name <env_name> python=3.10
    ```

2. Activate the environment:

    ```bash
    conda activate <env_name>
    ```

3. Install the required packages:

    ```bash
    pip install -r requirements.txt
    ```

4. Configure your environment variables by creating a `.env` file in the root directory and adding your API keys (e.g., Google Gemini API):

    ```bash
    GOOGLE_API_KEY=your_api_key_here
    ```

5. Run the application:

    ```bash
    python -m fastapi dev api/main.py
    ```

## Usage

Once the application is running, you can interact with the API via the following endpoints:


### PDF Upload

- **Endpoint**: `/v1/pdf`
- **Method**: POST
- **Description**: Uploads a PDF and returns the generated `pdf_id`.
- **Request Example**:

    ```bash
    curl -X POST "http://localhost:8000/v1/pdf" -F "file=@/path/to/your/pdf/document.pdf"
    ```

- **Response Example**:

    ```json
    {
        "pdf_id": "unique_pdf_id_123"
    }
    ```

### Chat with PDF

- **Endpoint**: `/v1/chat/{pdf_id}`
- **Method**: POST
- **Description**: Sends a message to interact with the uploaded PDF's content.
- **Request Example**:

    ```json
    {
        "message": "What is the main topic of this PDF?"
    }
    ```

- **Response Example**:

    ```json
    {
        "response": "The main topic of this PDF is about artificial intelligence advancements."
    }
    ```

## API Endpoints

- **POST** `/v1/pdf`: Uploads a PDF and returns a unique `pdf_id`.
- **POST** `/v1/chat/{pdf_id}`: Sends a message to the uploaded PDF and receives a response from the LLM.
